# agora-skills

Research skills for AI agents: how to find and cite academic and grey literature and official statistics through public, keyless APIs (World Bank, IMF, UN agencies, OECD, academic indexes).

Each skill is a folder with a `SKILL.md` (what it is for, when to use it, how to call the API, how to cite what comes back) and `scripts/` in Python standard library only, so they run in any sandbox without installing packages.

Built by the World Bank Group Institute for Economic Development for AVA's Computer mode and for any agent that reads the SKILL.md format. Work in progress.
